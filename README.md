# ue_2 — СКВ в игровом движке Unreal Engine

Учебный проект по лабораторной работе №2 дисциплины «Основы профессиональной деятельности» (ИТМО, Школа разработки видеоигр).

Основа — шаблон **Realistic True First-Person Movement Template V1** с Fab: персонаж от первого лица умеет бегать, приседать, наклоняться, прыгать, а также перелезать и перепрыгивать через препятствия высотой 1 и 2 м. На демо-уровне `L_Default_DevMap` команда добавила паркур-трассу, батуты и физические предметы.

## Скачать игру

**[Releases → v1.0.0](https://github.com/vxyun65/ue_2/releases/tag/v1.0.0)** → `Windows.zip`. Распакуйте архив и запустите `ue_2.exe`. Нужна Windows 10/11 x64.

## Что добавлено на уровень

- **Паркур-трасса** (Джуниор): платформы, лестницы и рампа из геометрии LevelPrototyping — 36 объектов.
- **Батут `BP_JumpPad`** (Сеньор): Blueprint, который подбрасывает персонажа при касании (On Component Begin Overlap → Launch Character). На уровне 3 батута.
- **Физические предметы** (Сеньор): 5 статуй из Starter Content с включённой физикой, их можно толкать.

## Как открыть проект

1. Установите **Unreal Engine 5.8** и **Git LFS**.
2. Клонируйте репозиторий:
   ```bash
   git lfs install
   git clone https://github.com/vxyun65/ue_2.git
   ```
3. Откройте `ue_2.uproject`. Проект сделан только на Blueprint, компилировать C++ не нужно. Первое открытие займёт время: компилируются шейдеры.

## Как устроена работа с Git

- **One File Per Actor.** Уровни `.umap` бинарные, Git не может их слить. Поэтому для `L_Default_DevMap` включён режим One File Per Actor: каждый объект уровня хранится отдельным файлом в `Content/__ExternalActors__`. Ветки Джуниора и Сеньора добавили разные файлы и слились без конфликтов.
- **Git LFS.** Самый большой файл проекта, `SKM_Quinn.uasset` (38 МБ), хранится в Git LFS: см. `.gitattributes`.
- **Генерируемые папки** `Binaries`, `Intermediate`, `Saved` и `DerivedDataCache` исключены через `.gitignore`.
- **Упаковка без Zen Store.** В `Config/DefaultGame.ini` отключён Use Zen Store (`bUseZenStore=False`): на машинах без работающего IPv6-loopback упаковка с ним падает с ошибкой «Failed to delete oplog on the ZenServer».

## Правила работы с репозиторием

- Ветки тематические: `feature/…`, `fix/…`, `ci/…`, `docs/…`. В `main` изменения попадают через pull request.
- Коммиты на английском в формате Conventional Commits (`feat:`, `fix:`, `ci:`, `docs:`, `chore:`), атомарные.
